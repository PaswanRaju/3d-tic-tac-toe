# 3D Tic Tac Toe

A modern, responsive Tic Tac Toe game with a futuristic 3D-inspired UI, animations, score tracking, and polished interactions.

## Features

- 3D-inspired game board
- Neon/glassmorphism interface
- Smooth X and O animations
- Win detection
- Draw detection
- Score tracking
- Restart round
- Reset scores
- Responsive design
- Built with HTML, CSS, and JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript
